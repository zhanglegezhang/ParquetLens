## M5 基准与优化：0.6.0，2026-10-30

交付 exe **11,750,912 字节（11.75 MB）**，NSIS **3,078,463 字节（3.08 MB）**。exe 比 0.5.1 缩小 34.3%；12 MB / 8 MB 体积目标均达标。功能回归和安装验收通过；性能目标并非全部达标，见下表与限制。

### 改动与取舍

- release 改为 opt-level="z"，保留 fat LTO、单 codegen unit、strip、panic="unwind"、所有类型和五种压缩格式。没有 UPX、功能裁剪或数据迁移。
- UTC 枚举分页借用已有结果，避免整份结果克隆；摘要直接复制元数据，不先复制全部枚举值再丢弃。
- 高基数/资源上限终止时释放计数容器容量；前端去重同一请求的事件与最终响应，避免重复取页和刷新。
- 以上减少临时复制和滞留容量，但不等于已达到 150 MB 空闲目标。标准基准受到 WebView2、分配器和界面生命周期影响，不把单次波动归因于某一优化。

| 构建 | exe MB | 原样本全列枚举中位数 ms | 比较次数 |
|---|---:|---:|---:|
| 0.5.1 / opt=3 | 17.89 | 2936.6 | 20 |
| M5 候选 / opt=s | 13.40 | 2929.8 | 5 |
| M5 候选 / opt=z | 11.75 | 6872.8 | 5 |

选择 z 是体积优先的明确取舍：扫描和抽样较 opt=3 变慢，但本机最终扫描/导出指标仍在目标内。候选为 0.5.1 版本号的独立离线测试构建；以下结果来自最终 0.6.0 的精确 SHA256 对应 exe。

### 环境与测量方法

Windows 11 26200、Ryzen 7 6800H（8核16线程）、约16 GB物理内存、D盘NTFS、WebView2 156.0.4314.50；Rust/Cargo 1.99.1、Node 24.22.0、Python 3.12.14。应用任务与本项目编译串行；保留用户其他桌面程序，不把本机成绩外推到其他机器。
每个文件先完整预热一轮，再记录20轮；不剔除慢样本。下表均为 **中位数 / P95 / 最大值，单位 ms**，P95 使用 nearest-rank。IPC 是真实 release 后端；界面计时在页面内发起操作并等目标DOM及两帧，含WebView2/CDP开销。预览完整1000行分两次500行读取；首屏显示单列为500行页的虚拟表格。
原样本 803,958,825字节、2000万行、50列、80 RG、Snappy，其中45列组内恒定，可能走footer捷径。混合 Snappy 819,175,011字节、Zstd 820,331,058字节，各1000万行、50列、40 RG；包含随机int64、组内混合100种分类值、约5% NULL、字典字符串。混合数据固定种子20261030。PyArrow独立计数逐值校验；两种压缩的首/尾完整RG相等。

**没有重启计算机或清空系统缓存。真正冷启动、冷磁盘打开均未测，不能以预热或新WebView配置代替。**

### 未达标项与边界

- 空闲≤150 MB未达标：进程树主要由WebView2占用，Rust结果复制优化不能消除浏览器基线；本轮没有禁用安全功能、替换渲染器或用工作集清理冒充内存优化。
- 缓存显示和打开界面存在超过目标的样本；以各表P95/最大值为准。缓存IPC远小于总显示耗时，余量包含布局、绘制、事件调度；z又增加后端处理耗时。不能把一次IPC返回时间当作用户可见完成时间。
- 真正冷系统缓存/重启后启动未测，需要另行安排；当前结果不能证明1秒冷启动和冷磁盘打开目标已达成。新WebView配置的实测启动也有超过1秒的样本，见上表。
- 真正Win10 1809、UNC共享、无WebView2机器仍未覆盖；本轮为本机Windows 11验收。

### 测试与安装验收

58项Rust测试、2项前端测试、Svelte检查、fmt、Clippy全部通过。新增摘要完整性、停止计数后共享预算不污染其他列，以及Snappy/Gzip/Zstd/LZ4/Brotli数据页解码回归。

真实NSIS验收链路：0.6.0全新安装→默认卸载；0.4.0→0.5.0→0.5.1→0.6.0升级；重装；默认保留个人数据卸载；显式清理卸载。0.6.0安装/升级/重装/卸载均不注册右键菜单；旧版所属菜单由兼容清理逻辑删除，默认文件关联不变。安装版与便携版分别记录SHA256：仅Tauri内置打包类型标记有3字节差异（UNK→NSS），归一化该标记后逐字节一致。初次逐字节相同断言因此失败，查明框架行为后修正验收规则；另修正验收脚本恢复注册表时的只读句柄写入问题。原数据校验恢复后从头完整重跑安装链路通过，应用与安装包无需重构建。
已安装exe验证中文/空格路径、第二实例转交、设置保留与不自动恢复标签。测试安装最终卸载；原个人文件、WebView文件和原安装偏好已校验恢复，未留下测试常驻实例。原始备份留在test-results，不纳入交付。
